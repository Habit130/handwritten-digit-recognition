# ADR-0033：首个版本提供三档受控挑战路线

## 状态

已接受

## 背景

全局策略要求难度通过学习者承担的责任区分，最低路线直接使用预训练模型，最高路线需要自行获取数据并完成核心代码，但不能要求初学者从空白仓库构建完整系统。

## 决策

首个版本固定三档路线：

1. **直接运行**：配置环境，把项目提供的 `mnist_cnn.pth` 放到指定位置，加载并完成真实实验。
2. **跟随训练**：使用项目提供的完整训练程序下载 MNIST、训练、保存 `model.pth`，再加载并实验。
3. **核心挑战**：在项目提供的受控骨架中完成模型创建、训练循环和保存三个核心 TODO，下载 MNIST、训练、保存 `model.pth`，再加载并实验。

三档路线共享同一网络结构、知识解释、API、可视化和兼容性验证。路线不记录进度，也不把准确率作为自行训练模型的准入条件。

每档模型路径固定并由 API allowlist 管理：

- 直接运行：`assets/models/mnist_cnn.pth`
- 跟随训练：`workspace/practical/model.pth`
- 核心挑战：`workspace/challenge/model.pth`

## 后果

路线差异聚焦于训练责任，不衍生三套课程或运行时。挑战骨架中的 TODO 是有意保留的学习任务，不属于产品实现缺失。
